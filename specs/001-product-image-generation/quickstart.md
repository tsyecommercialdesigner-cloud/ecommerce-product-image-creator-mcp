# 验证指南与历史计划

## 当前状态（2026-11-13）

项目已有本地 stdio Server 和锁定依赖。负责人已验收 Sunburst、Flare 各自的 Form 与 Mock 真实结果，覆盖 Form 一张及 Mock 两张输入；更大输入组合尚未实测。当前成员安装与操作步骤见 [README](../../README.md) 和 [MANUAL](../../MANUAL.md)。当前工作区尚未形成包含这些实现的已发布版本；旧提交的 CI 和历史全量测试不代表当前代码已通过 CI。

Team Mode 默认启用，但实际生成、远程查询和下载须分别开启；unknown 不自动重新提交。Form 审核及 Mock 输入变更尚缺少成员可用的完整入口，多实例并发下载也未完成验证。T051–T060、T062–T063 的正式任务状态仍以 tasks.md 为准，真实图片验收不自动改变任务复选框。

下文保留的是早期验证计划及历史假设，涉及“尚未实现”、严格授权、自动重试和待编写手册的描述不代表当前 Team Mode 的运行状态；不得将其视为当前使用步骤。

本文件是验证方案，不代表源码、依赖、检查入口或 Host 集成现已存在。不得调用真实上游或修改 Host，除非另获明确授权。配置与安装按 [交付指南](../../docs/delivering/MANUAL-WRITING-GUIDE.md) 在实现完成后从实际发布版本编写；以下标为待补的命令不得当作可运行命令。

Phase 2A 安全恢复规则：绘图模型仅在每模型/端点最多三次、总计最多六次（均含首次）的范围内，在安全且授权覆盖时按 Sunburst→Flare 切换；普通重试等待 5 秒，429 缺少有效 `Retry-After` 停止。429、5xx 或超时本身不能证明远端未执行；unknown 不重提。故障分类、模型/端点/分组兼容及费用授权范围尚未实测，本段不是已实现或已验证的自动恢复功能。

验证对象是本项目独立实现的 MCP Server 与其直接调用供应商的适配层，不依赖其他 MCP 服务。先用替身独立验证，再经授权以本项目适配层进行真实调用；此前其他 MCP 的结果不替代本项目验证。

## 前提与准备

1. 确认服务选型与 Host 授权能力的验证范围，记录图片大小和总量决定，固定 Python、SDK、协议、依赖和锁文件；按照实际权限与配置加载规则准备隔离测试环境，使用无真实权限的假密钥。Host 能否提供可由 Server 验证的证据须另行测试，不假定已支持。
2. 在实际实现的 `pyproject.toml`、`uv.lock`、模块入口及测试脚本存在后，按项目文档执行 `uv sync --locked` 及实际验证命令；缺失任一项即停止。成员运行使用相应 `uv --no-sync` 入口；不在工具启动时安装或构建。真实安装命令和参数待实现并验证后回填，不虚构路径。
3. 记录 OS、Python、uv、SDK、协议和 Host 版本、校验命令、退出码、预期及结果；本地临时文件放工作区内隔离目录，只清理本次创建资源，证据脱敏。

## 分层验证矩阵

| 层次 | 输入和操作 | 必须观察的结果 |
|---|---|---|
| 输入及业务单元 | 设计 0/1/2/3、形态 0/1/6/7，JPEG/PNG/无效格式；真实内容、路径越界、重解析点、输入替换、异常解码、资源不足和已声明限制 | 合法例通过；无权访问、内容无效或资源不足安全停止并定位问题；不设固定业务文件大小上限不等于无限资源；具体技术保护及供应商限制须验证 |
| 授权及状态 | 模拟授权缺失、范围不符、并发两个进程、修订；对于实际支持可验证凭证的 Host，另测过期、错误主体及重放 | 未授权 0 次上游提交；同一尝试最多一个发送资格；一次授权覆盖的尝试数按实际机制和明确授权判断；输入变化使批准失效；伪造布尔值无效 |
| 适配器替身 | Host Agent 传入实际提示词，Server 记录版本/摘要并绑定任务、参考快照、授权和尝试；模拟成功、失败、超时、无 ID、可查询 ID 与保存失败 | Server 不调用独立 LLM；提示词变化使相应确认/授权失效；未知结果不自动重提，保存失败独立报告；Host token 不视为 Server 已计量成本 |
| 供应商格式 | 验证默认 `gpt-image-2.5-sunburst`、逆向组与异步 Edits，及获授权且经验证的备选 `gpt-image-2.5-flare`；按组合检查 `image`/`image[]`、阶段数量、UTF-8、ID、状态、结果与 `cost` | 不自动切换绘图接口；仅安全且授权覆盖时切换备选模型；组别和各组合能力未实测前不声称兼容，缺失费用为 unknown |
| 崩溃恢复 | 提交意图事务前后、网络发送前后、上游 ID 持久化前后、结果下载/文件发布/数据库登记间中断；文件缺失、损坏、权限拒绝、磁盘满、重复恢复并发 | 分别报告本地、上游、交付状态；核对 task_id 和摘要，证据完整才补登记；未知不重提，损坏不冒充成功，上游成功不改为失败；仅可重取同一结果 |
| 有限重试与切换 | 模拟安全技术故障、每模型/接口最多 3 次、默认与备选总计最多 6 次（均含首次）、重启和更换 attempt ID；模拟多轮人工修订 | 仅在安全且费用授权覆盖时执行，未知结果不重提或切换；429、5xx、超时本身不证明未执行；拒绝不可绕过，修订为独立操作 |
| 退避与本地去重 | 假时钟验证普通失败 5 秒、429 的有效/缺失/无效 `Retry-After`、重启及并发；绘图同操作标识同摘要及不同摘要 | 仅安全且已授权时等待后重试；429 缺失或无效时停止并报告；同操作不重复发送、摘要冲突拒绝；发送窗口未知时保留 unknown，不声称远端恰好一次 |
| MCP 协议 | 使用项目锁定 SDK 的真实客户端与本地 stdio 子进程，发现工具、测试输入/输出 schema、权限错误、isError、图片/元数据及异常 | 依据实际协议返回，不把错误或 unknown 伪装成功；stdout 仅协议；日志与返回不泄密 |
| Host 联调 | 经允许在具体版本 Codex、Claude Code、DeepSeek Harness 配置隔离服务，检验原生 Interrupt/Permission、工具标识、Server 可见证据、本地路径、图片展示与 Host 退出 | 逐 Host 记录版本、实际交互、Server 可见证据和不支持项；不假定 Host 退出后后台任务继续 |
| Host 授权核对 | 在受控 Windows 本机单用户环境，以 [已有替身记录](contracts/host-permission-probe-2026-11-02.md) 为基线，分别验证 Codex、Claude Code、DeepSeek Harness 的人工允许/拒绝、任务及费用范围、失效与 Server 可见证据 | Host 自动批准或工具可调用不等于业务授权；不能以调用 ID、模型文本、`approved=true` 或 API key 证明授权；无法落实实际授权核对时停止收费，无法独立验证须标记 `unverified` |
| Host 人工审核交接 | 对各 Host 用独立 Server 与替身展示形态及当前 mock，实际暂停等待人确认、拒绝或提交修订，并按该 Host 支持的机制恢复；覆盖版本变化、旧确认与重启 | 记录 task/revision、对象、版本、摘要和来源；确认只作用于审核对象，拒绝/等待不推进；不假定各 Host 都支持 `app.ainvoke(resume=...)`，缺少可验证来源标记 `unverified` |
| 真实上游 | 逐次取得具体测试的费用和数据授权，选定模型/端点/组别及尝试范围，执行授权测试并保存原任务标识 | 未知结果仅查询已有任务、不自动重提；记录可得绘图 cost、耗时及不可得项，不把 Host token 当作 Server 已计量费用 |
| 人工验收 | 用授权素材审核六视图形态组合图及标识，再审核一张六视图包装 Mock 组合图，检查品牌、文字、关键结构与 Q 正交 | 未确认形态不得生成 Mock；Mock 只输入已接受形态组合原图与一至两张设计图，人工可请求修订并保留历史，最终裁决由业务人员负责 |

## 端到端流程（未来实现后）

使用隔离 Host 和假服务提交一至两张设计图及一至六张形态图。形态阶段一次生成一张 F/L/R/B/T/Q 组合图并经人工确认；Mock 阶段只使用确认的形态组合原图和一至两张设计图，一次生成一张六视图包装 Mock 组合图供人工审核。两阶段均可明确请求修订并保留历史；验证任务、提示词、attempt 和产物关联、unknown 不重提及授权边界。真实视觉效果由运营人员判断。

命令、精确工具调用示例和期望退出码在实际入口及契约落地后回填；在此之前上述流程是待执行的验证要求，不是已通过结果。
