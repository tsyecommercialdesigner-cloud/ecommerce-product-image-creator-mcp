# 未来实现后的验证指南（当前不可运行）

本文件是验证方案，不代表源码、依赖、检查入口或 Host 集成现已存在。不得调用真实上游或修改 Host，除非另获明确授权。配置与安装按 [交付指南](../../docs/delivering/MANUAL-WRITING-GUIDE.md) 在实现完成后从实际发布版本编写；以下标为待补的命令不得当作可运行命令。

## 前提与准备

1. 完成服务选型、可信授权签发与验证、图片大小和总量决策，固定 Python、SDK、协议、依赖和锁文件；按照实际权限与配置加载规则准备隔离测试环境，使用无真实权限的假密钥。
2. 在实际实现的 `pyproject.toml`、`uv.lock`、模块入口及测试脚本存在后，按项目文档执行 `uv sync --locked` 及实际验证命令；缺失任一项即停止。成员运行使用相应 `uv --no-sync` 入口；不在工具启动时安装或构建。真实安装命令和参数待实现并验证后回填，不虚构路径。
3. 记录 OS、Python、uv、SDK、协议和 Host 版本、校验命令、退出码、预期及结果；本地临时文件放工作区内隔离目录，只清理本次创建资源，证据脱敏。

## 分层验证矩阵

| 层次 | 输入和操作 | 必须观察的结果 |
|---|---|---|
| 输入及业务单元 | 设计 0/1/2/3、形态 0/1/6/7，JPEG/PNG/无效格式；精确上下限和超限文件；缺类别、路径越界、重解析点、替换输入 | 合法例通过；超限或无权访问定位图片并在收费前拒绝，未确认版本/子集与冲突停止；缺失结构不声称还原 |
| 授权及状态 | 假凭证缺失、过期、错误主体、版本/摘要不匹配、重放、并发两个进程、修订 | 未授权 0 次上游提交；同一有效凭证最多一次发送资格；输入变化使批准失效；伪造布尔值无效 |
| 适配器替身 | 真实响应映射、成功单图、明确失败、超时、断线、无 ID、有可查询 ID、保存失败；供应商 SDK 重试关闭 | 使用量缺失表示 unknown；超时不自动重提、不声称失败；可查询只查原 ID；已成功但保存失败独立报告 |
| 供应商格式 | 对照 [适配契约](contracts/provider-adapters.md) 验证两个默认 `-2k` 模型、逆向组与异步 Edits，显式指定备选端点、Nano 多参考图编辑及用户确认的无后缀/`-2k`/`-4k` 异步查询覆盖；逐组合检查 `image`/`image[]`、输入和输出限制、UTF-8、ID 及状态、URL/空 Base64、`cost` | 未经显式指定不切换端点；不支持组合拒绝；无 ID 或未识别状态不重提；有效 `cost` 保留，缺失为 unknown，无单位不猜测，多次查询不重复累计 |
| 崩溃恢复 | 提交意图事务前后、网络发送前后、响应/本地文件登记间分别中断并重启 | 无自动再次收费；保持 attempt、授权消费和可验证证据；未明确时 unknown；历史产物不归当前尝试 |
| MCP 协议 | 使用项目锁定 SDK 的真实客户端与本地 stdio 子进程，发现工具、测试输入/输出 schema、权限错误、isError、图片/元数据及异常 | 依据实际协议返回，不把错误或 unknown 伪装成功；stdout 仅协议；日志与返回不泄密 |
| Host 联调 | 经允许在具体版本 Codex、Claude Code 配置隔离服务，检验工具标识、授权边界、本地路径、图片展示与 Host 退出 | 逐 Host 记录兼容、不支持项及版本；不假定 Host 退出后后台任务继续 |
| 真实上游 | 事先逐次授权费用和参考数据，选定实际模型，执行一次测试并记录原始任务标识 | 仅查询已有任务，不自动重复提交；记录真实响应、可得费用/usage/时长及不可得项；未知结果停止并告知风险 |
| 人工验收 | 用授权素材审核一张候选，审查 Logo、文字、已确认关键结构及其他视觉差异 | 业务人员拥有最终裁决，外部流程记录结果；替身或自动评分不代替实际审查 |

## 端到端流程（未来实现后）

使用隔离 Host 和假服务提交 1–2 张设计与 1–6 张形态 JPEG/PNG，提供每张类别和要求；检查待确认版本、冲突、拟用子集及费用/时长可得性。完成可信审批后仅提交一次，按 task/attempt 查询；确认成功返回该次唯一候选文件及归属摘要。再模拟无上游 ID 的超时：状态 unknown、告知风险、不自动重试；仅在新的明确授权后创建关联尝试。检查输出及记录不包含真实秘密和无关任务。

命令、精确工具调用示例和期望退出码在实际入口及契约落地后回填；在此之前上述流程是待执行的验证要求，不是已通过结果。
