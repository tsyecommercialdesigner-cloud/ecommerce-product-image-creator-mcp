## 共用素材与流程

选一件负责人有权使用、无客户隐私的普通电商商品；负责人提供或批准有权向供应商上传的真实商品 Form 照片及包装设计素材。记录素材来源、用途许可、各图片顺序、实际 MIME、字节和 SHA-256，避免上传个人信息和真实客户资料。若使用品牌、商标或第三方图片，先确认使用范围。当前商品、图片及许可均未确定，不能预先填写伪造摘要。

每个 Form 生成目标是一张含 F/L/R/B/T/Q 标签的六视角组合图；人工审核通过并绑定真实 Artifact 身份后，才可用该模型的 Form 结果进入 Mock。Mock 生成目标也是一张六视角包装组合图。用相同商品、可比业务要求及同一批有权使用素材；人工审核需核对形状、方向、细节、包装、文字和品牌，不以生成成功代替通过。输出须经过现有安全下载、无覆盖保存及 SQLite 登记，并人工核验；不能将下载失败改写为生成失败或重新生成。

## 费用、等待和停止条件

- 四项生成的单次价格、总价及账号组为 unknown；不将历史 `cost=0` 当成免费或已结算。请求前分别展示模型、阶段、端点、组、素材摘要、提示词摘要、执行摘要、最大一次发送、费用或 unknown，取得适用于该次的明确批准；旧范围授权不能自动覆盖新的实际请求。
- 查询 `GET /v1/images/tasks/{task_id}` 和结果下载的费用属性、允许来源、价格及下载授权均 unknown，按可能收费处理，每次适用独立许可；Host 模型测试许可不涵盖绘图、查询或下载。冻结合法上游 ID 后仅通过原任务查询，等待与查询次数、间隔及总体时间由具体授权和可信配置预先限定；无授权不得轮询。
- 无 ID、超时、断连、矛盾响应或未可信持久化 ID：保留 unknown、费用风险及原 Attempt，停止；不得猜 ID 或自动重提。已取得可信 ID 时按独立授权查询；上游明确失败、字段或数量不兼容、认证／权限／安全错误、下载不安全、磁盘不足或人工审核不通过时停止并报告。不得自动切换字段、模型或端点、丢图、覆盖文件或释放未知费用风险。
- 成功、失败、未知和未执行均记录脱敏模型、端点、可见分组、素材／提示词／执行摘要、原任务 ID、状态、耗时、产物摘要和有来源的费用事实；签名 URL、密钥、用户资料不入报告。响应费用与真实账单分开；无独立账单证据时保留未核实。
