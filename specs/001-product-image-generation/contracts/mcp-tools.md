# MCP 工具契约（候选，未实现）

MCP Server 名称与 Host 暴露名称、SDK 方法和具体 JSON Schema 均待锁版本联调。本契约规定业务字段及约束，非已实现 API。供应商模型、端点、分组和响应的适配约束见 [供应商适配契约](provider-adapters.md)。工具发现不等于授权；`isError` 或结果状态按锁定 SDK/协议实测映射。绝不使用默认重试的供应商 SDK：显式关闭请求重试并验证网络层无隐式重提。

## prepare_product_image

**用途**：创建本地任务草稿并校验参考资料、展示摘要及可得的费用/耗时信息。**副作用**：只写本地任务/摘要，不提交图像生成，不自动进行收费视觉识别。

**输入**：`references[]` 每项 `{category: artwork|form, path: string, view?: string, purpose?: string, importance?: string, version?: string, region?: string}`；`instructions` 非空；任务须明确使用两个默认 `-2k` 模型中的哪一个，或由用户显式指定其他受支持的模型及端点；默认异步 Edits 和逆向组，其他端点仅在用户显式指定时使用。可选运营人员已知的版本、结构冲突及选择说明。分别为 artwork 1–2、form 1–6；JPEG/PNG；路径限制及单图/总大小按批准的配置声明；类别必填，视角可选。相对路径、远程 URL 与根外路径不接受。缺失、错误、越界、链接/重解析点越界和超限返回可定位具体图片的安全错误，不泄露密钥或本地私密内容。

**输出**：`task_id`, `revision`, `input_digest`, 分类/所选清单、验证状态、可得费用与耗时信息的值/来源/unknown、待确认的版本/结构/资料选择。业务选择与收费授权由独立可信确认路径记录并绑定 task/revision/digest，普通模型文本不证明确认；具体交接见 [架构审查决策](architecture-review.md)。任何输入、选择或模型端点变更都使此前确认/授权失效。系统不推断未观察结构真实还原；若无法可靠识别冲突，须报告未能确定并让运营人员补充/确认，不能伪称所有信息已检查。系统可建议子集，必须由用户明确确认，确认后仍须满足每类最低要求。检测/筛选算法是否需要模型与是否收费待选型；有收费时必须独立获得授权，不能静默在 prepare 发起。

## submit_product_image

**用途**：提交一次已确认的尝试；**副作用**：向上游发送图片与文本、可能产生费用、写任务与产物。调用返回本地 attempt ID 和当时已知状态，之后查询；无权假定后台进程能存活到 Host 关闭。

**输入**：`task_id`, `revision`, `input_digest`, `authorization_reference`；版本/结构不确定性和选择结果由绑定 revision 的可信确认表达；新尝试须传 `previous_attempt_id` 和新的风险确认授权。`authorization_reference` 是可验证的一次性凭证引用，不是布尔字段；服务端必须验证其来源、主体、有效期、任务、修订、图片摘要、供应商/模型、付费操作和风险范围，并在数据库中原子消费。可信授权签发/验证方案目前未定，未接通必须拒绝；不得通过话术、工具描述或 Host 可调用性替代授权。耗时/费用可获得信息变更影响授权范围时重新确认。

**输出**：`task_id`, `attempt_id`, `status`、如已知的脱敏上游标识。重复同一授权或并发提交返回原有本地 attempt 引用/冲突，绝不发送第二次；持久化失败禁止发起上游。提交超时或服务中断以 unknown 呈现并停止，不能返回成功或明确失败；对可查询的原上游 ID 使用只读状态查询。新尝试仅在新的明确授权和风险告知后创建，保留旧记录。

## get_product_image_task

**用途**：只读查询指定 `task_id` 及可选 `attempt_id`，默认列出该任务的当前尝试及可追溯历史；可按已获得的上游 ID 进行有界只读状态查询，禁止通过查询隐式触发收费重提。**副作用**：可更新本地记录以反映有据可查的上游状态；不生成图片。

**输出**：`task_id`, `revision`, `attempt_id`, `previous_attempt_id?`, 状态、证据来源、unknown 风险说明、上游状态（可空）、时间、usage、费用、耗时及其来源/unknown；费用按供应商返回的有效 `cost` 记录，缺失或无效则为 unknown，币种/单位未知时不得猜测；成功时返回一个经授权可访问的本地候选图引用、摘要、MIME 与必要审核信息。不得以路径或 ID 允许越权读取其他任务；不将外部审核结果作为本服务状态。图像块作为可选预览，真实 Host 图片消费能力、结构化内容组合及输出大小需实测；调用方只能访问已授权产物根。

## 状态与错误

返回本地任务状态、上游尝试状态和本地交付状态三个独立字段，定义见 [数据模型](../data-model.md) 与 [架构审查决策](architecture-review.md)。上游成功而下载/保存失败时分别报告；`unknown` 包括可能仍运行及重复费用/产物风险，不标记失败或取消。该自定义业务任务接口不声明实现 MCP Tasks Extension。

错误语义：无效参数、禁止访问、缺失权限、文件超限和确认缺失为可纠正工具执行错误，按 SDK 返回 `isError: true`；协议无效请求由协议层处理。持久化失败或授权验证失败 fail-closed。发生未知状态时输出结构化 unknown 和风险；是否采用 `isError` 及 schema 兼容由锁定 SDK 协议检查确认，不能把未知当作业务成功。详细错误脱敏，stdio stdout 仅协议，stderr 不含秘密。

## 当前阻断与兼容范围

可信授权凭证由谁签发、如何绑定人工确认和受信身份尚无已验证方案；默认模型、端点和分组已由用户明确，但任务中的模型选择、逐组合图片限制和 Host 兼容仍需确认。以上接口是评审草案，不得宣称实现或直接启动收费调用。
