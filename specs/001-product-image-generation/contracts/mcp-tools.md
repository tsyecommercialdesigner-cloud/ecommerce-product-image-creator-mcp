# MCP 工具契约

## 当前实现状态（2026-11-13）

本地 stdio 已提供 Prepare、Submit、Get Task 及读取已登记原图的 `get_product_image_file`。Team Mode 默认选择，生成、查询及下载开关默认关闭；已启用时的业务操作和限制见 [成员手册](../../../MANUAL.md)。Sunburst 和 Flare 的 Form、Mock 在指定输入组合下已完成真实图片验收，结果见 [验收记录](../evidence/mvp-team-acceptance-20261113.md)。以下历史契约仍包含早期 Strict 授权及候选接口描述；其中未实现、待联调和自动重试条文不得直接视为当前 Team 实现。

供应商模型、端点、分组和响应的适配约束见 [供应商适配契约](provider-adapters.md)。工具发现不等于人工批准；`isError` 或结果状态按锁定 SDK/协议实测映射。Team Mode 未启用自动付费重试，未知结果不重提。

**分阶段业务契约**：形态阶段一次正常绘图产生一张 F/L/R/B/T/Q 六视图组合图，形态各视图左上角由模型标注约定字母；经人工确认后，Mock 阶段一次正常绘图产生一张包含六视图的包装 Mock 组合图，交运营人员审核。两阶段均可明确请求多轮修订并保留历史；Q 为右上 45° 正交。Host Agent 构造提示词，Server 不调用独立 LLM、不拆图或合成。

两个阶段各次正常生成操作均要求一次绘图返回一张六视图组合文件，不拆分、裁切或后处理合成；技术故障按已授权安全重试，unknown 不重提，人工修订为关联的新操作。

技术故障重试以逻辑生成操作为范围：每个模型与接口组合最多 3 次（含首次）；当前默认与备选绘图模型共用一个接口，单个逻辑操作最多 6 次（含首次），受实际安全条件和授权范围限制，同一操作重启或更换 attempt ID 不重置计数。运营人员主动要求并获适用授权的每轮形态或包装修订是关联历史的新操作，人工修订轮数不设上限，技术重试独立计数；不得将自动重试伪装为新修订。结果不明时仍须查询原任务，无法查询须保留 unknown 并取得新的风险授权后才能新尝试。

## prepare_product_image

**用途**：创建本地任务草稿并校验参考资料、展示摘要及可得的费用/耗时信息。**副作用**：只写本地任务/摘要，不提交图像生成，不自动进行收费视觉识别。

**输入**：`references[]` 每项 `{category: artwork|form, path: string, view?: string, purpose?: string, importance?: string, version?: string, region?: string}`；`instructions` 非空；默认绘图模型 `gpt-image-2.5-sunburst`、异步 Edits 和逆向组；其他端点仅在用户显式指定时使用。可选运营人员已知的版本、结构冲突及选择说明。分别为 artwork 1–2、form 1–6；JPEG/PNG；路径受允许根限制；首版不设固定业务文件大小上限，技术资源保护及资源不足处理须另行落实；类别必填，视角可选。相对路径、远程 URL 与根外路径不接受。缺失、错误、越界、链接/重解析点越界和超限返回可定位具体图片的安全错误，不泄露密钥或本地私密内容。

**参考资料观察记录（T033）**：每项可选 `observations` 列表；每条有 `subject`、`status`（`unknown`、`described`、`assumed`），描述或假设须提供来源 `operator|agent`、当前资料 `source_ref_id` 及 `description`；未知项不得附来源或描述。独立视觉核验当前不可用，不接受客户端声称 `verified` 或 `independent`。记录仅是声明和假设，不是视觉事实；非空记录保存于输入上下文并参与输入摘要及 v2 执行摘要，历史无记录保持原摘要。提示词阶段上下文及其品牌约束仍属 T034。

**输出**：`task_id`, `revision`, `input_digest`, 分类/所选清单、验证状态、可得费用与耗时信息的值/来源/unknown、待确认的版本/结构/资料选择。业务选择与收费授权按 Host 实际能力记录并绑定 task/revision/digest，普通模型文本不证明确认；具体交接见 [架构审查决策](architecture-review.md)。输入或业务选择变化使此前确认/授权失效；模型或端点切换仅在事先明确授权的自动恢复范围内继续，否则重新确认。系统不推断未观察结构真实还原；若无法可靠识别冲突，须报告未能确定并让运营人员补充/确认，不能伪称所有信息已检查。系统可建议子集，必须由用户明确确认，确认后仍须满足每类最低要求。Host Agent 负责理解及提示词构造，Server 不调用独立 LLM 或静默发起收费请求。

**执行快照准备**：接收当前阶段 Host Agent 实际提示词、任务及修订、参考集合、已确认形态版本（Mock 适用）、模型、端点、分组、输出设置和拟授权恢复范围。验证输入并持久化受控冻结图片字节及摘要、提示词正文/版本/摘要、任务修订与可恢复执行快照，形成覆盖实际内容和范围的 `execution_digest`；返回任务摘要、可得费用/耗时或 unknown。准备不调用供应商、不代表授权。T023 实现最小准备持久化；T024 后续扩展阶段提示词契约与修订，不是 T023 前置。

**当前已实现的 Prepare 接口**：必填 `references[]`（每项含 `ref_id/category/path/mime`）、`instructions`、`prompt`、`stage`；可指定 `model/endpoint/grouping/task_id` 及未经确认的 `structure_conflicts[]` 描述。形态阶段接收完整的两类任务资料，但执行快照的绘图参考仅包含形态图片；Mock 阶段要求 `task_id/artifact_id/review_id`，`references` 仅包含 1–2 张设计图，形态组合图从已登记产物读取。响应含任务、版本、阶段、输入及提示词摘要、执行摘要、模型/端点/分组、输出范围、有序阶段资料 ID、待确认项及费用/耗时 `unknown`；`authorization=unverified` 不代表批准。

`references_summary` 区分来源形态修订登记资料、当前选用资料和未参与的登记资料，按类别给出数量及 ID；Mock 使用来源形态修订的登记资料并另外列出实际选用的形态组合产物及设计图。`packaging_versions` 只报告实际资料上的版本标签，缺失为 null；多个不同标签提示待确认，不认定版本有效。`structure_conflicts` 报告调用方提供的描述与 `pending_clarification`，未提供为 `unknown`；来源和确认均未验证，不能当作真实人工决定。Mock 继承来源形态修订已记录的冲突。通过同一工具只传 `task_id` 与 `recovery_revision` 可读取已有准备响应，不创建修订；这不取代后续任务状态查询。可信业务确认交接和收费提交前的最终校验仍未实现。

输入摘要不变的形态修订保留已报告的冲突，不接受普通请求以空列表消除冲突；输入发生变化时重新报告该修订已知的信息，历史记录仍可追溯。冲突描述保存在独立记录而非修改既有 v2 快照，因此后续收费入口必须同时核对其状态和适用的可信确认。

**必要性与替代方案**：原契约仅在 `submit` 首次接收提示词，无法让 Server 在收费前形成含实际提示词的快照。扩展现有 `prepare_product_image` 可保持三工具并明确先准备、再确认、后提交；由 Host 自行展示 `submit` 参数的替代方式仅在实际 Host 能展示完整内容并可靠绑定不可变快照时才可考虑，不能假设所有 Host 均支持。两种方式都不引入独立 LLM 或用布尔参数证明确认。

本契约的三个业务工具及授权交接在 Phase 2A 仍未实现；无收费协议探针不提供这些业务工具，不作为 Host 核对或授权证据。提交及人工确认由后续 T016、T023–T028 和三 Host 联调分别落实；未能核对授权时不得收费提交。

**形态审核记录契约**：审核记录关联 review_id、task_id、形态版本、Artifact ID 和内容摘要，保存 `accept/reject/pending` 决定、来源、时间、可选到期时间及证据引用，并支持记录失效及原因。Mock 准备须核对当前版本、产物与最新审核决定，拒绝缺失、跨任务、篡改、拒绝、失效、过期及不可信来源；默认来源验证器拒绝，测试替身不配置为生产来源。来源状态未验证为 `unverified`，标识、布尔值、模型陈述及 API Key 不能证明人工审核。审核与新的收费操作授权相互独立，不能以审核通过代替费用授权。

**形态离线记账子范围**：本地接口可登记已安全读取、摘要匹配且已记录上游成功的形态产物，拒绝同一 Attempt 的第二个产物；可另行记录前一形态修订、Attempt 和修订说明，并读取当前或历史状态。数据库交付状态与按受控根目录重新核验的文件可读性分别报告。该登记不执行下载或生成，修订关联不是自动创建、也不证明说明来自真人；文件与 SQLite 不是同一原子事务。实际生成、完整修订交接、Host 来源核验及收费授权仍未实现。

**形态修订离线契约**：修订请求保存 Task、来源形态修订、Attempt、Artifact 摘要、拒绝审核、说明与来源；来源状态保留 `unverified`，生产来源验证默认拒绝。请求消费时在 SQLite 事务中重新核验来源、拒绝审核和产物，并使用原冻结输入创建新 v2 快照及关联记录；请求不可重复消费。通过目标修订查询后续 Attempt，可追溯旧操作但不继承其授权。Form Prepare 响应及提示词上下文提供一张 F/L/R/B/T/Q 组合图、每视图左上角标识、Q 右上 45° 正交和不使用旧候选作输入的要求；Host 构造实际提示词，Server 不自动修改文本，视觉质量和真实 Host 交接尚未验证。

**Mock 离线审核与修订子范围**：一张 Mock 组合产物绑定任务、Mock 修订、Attempt 和摘要，并经准备快照追溯形态来源与设计版本。审核记录针对整张产物，可附 F/L/R/B/T/Q 单区域反馈；来源保留 `unverified`，生产来源验证默认拒绝。拒绝后的修订请求经隔离替身核验时，在同一 SQLite 事务中复制原冻结输入并创建新 v2 快照，不继承旧审核或授权；读取链可关联后续 Attempt。该能力不下载或生成图片、不证明真人批准，实际 Host 交接、交付复核和视觉验收仍待完成。

同一任务、形态版本、产物及摘要存在未失效且未过期的 `accept` 和 `reject` 决定时，暂停并要求澄清，不以记录先后覆盖冲突。冲突排除后，按本地记录插入顺序核对该形态版本的最新审核记录；过期、失效或 pending 记录不能放行。Mock 本地资格创建与消费时在 SQLite 写事务内重新核对审核及来源；历史快照仍可读取。真实 Host 审核交接仍须验证。

**摘要版本**：旧版快照仅保留历史读取；新资格创建、消费和将来的提交均须核验完整 v2 快照，不得重新计算旧摘要后继承旧确认。T027 的提交入口须独立执行此检查。

**本地提示词上下文**：`read_prompt_context` 从已验证的 v2 准备记录恢复任务修订、实际文本、提示词版本/摘要、执行快照和适用的形态来源；`validate_prompt_context` 比较提交的提示词对象与该冻结版本，拒绝跨任务、阶段或同版本不同内容。形态上下文仅选择形态参考图，Mock 上下文包含形态组合产物及一至两张设计图；此接口不验证视觉结果、真实人审或收费授权，来源状态仍为 `unverified`。历史 v1 仍仅用于审计读取。

**阶段上下文离线子范围**：Prepare 和恢复响应返回从冻结记录重建的 `stage_context`，列出本阶段资料与声明观察、形态来源、品牌来源规则、未知结构及已报告的冲突。`operator` 等来源仅为未经验证的声明，假设不能成为已观察事实；视觉验证保持 `unverified`。对于单句、肯定式、明确标注 competitor brand 与 target brand 的有限英文替代声明，报告 `competitor_as_target` 和 `pending_clarification`；该判断依据声明本身，并未验证实际品牌身份。其他提示词，包括否定句、条件句及无法解释的表达，保持 `unverified`，不表示通过。检测结果由冻结 Prompt 恢复，不更改 Prompt 或快照摘要。后续收费入口 T027 必须处理此冲突和未验证语义，当前未实现该交接；不同包装版本与已报告结构冲突仍按既有离线提交门禁处理。

## submit_product_image

**T027-B1 无收费首次提交子范围**：MCP 请求在下述身份和摘要字段之外还须提供稳定的 `operation_id`；该标识只用于绑定和幂等，不是授权证据。Mock 请求另提供 `form_revision` 和 `form_artifact_digest`，均与已冻结来源匹配。Server 从已保存的 v2 记录恢复提示词、图片字节、模型和执行范围；不接收客户端替换这些内容。本子范围只支持首次提交或同一操作的只读幂等重放，不开放技术重试、跨模型或风险关联提交。Host 执行授权和生成费用授权分别校验并在提交事务中消费；生产来源验证和发送器默认拒绝。输出区分本地意图、发送边界、远程状态、产物交付及未知费用，隔离替身不证明真实供应商或 Host 已验证。

Mock 首次提交在本地资格消费事务中和发送边界前分别复核来源 Form 审核，并检查受控目录中的来源 Artifact 文件及摘要；实际提交仍使用冻结 BLOB。来源引用不匹配返回 `FORM_SOURCE_MISMATCH`，审核不适用或来源不可信返回 `FORM_REVIEW_UNVERIFIED_OR_INVALID`，来源文件不可安全读取或摘要不一致返回 `FORM_ARTIFACT_INVALID`。提交意图已登记后才发生失效时保留历史并保守报告不确定性，不将本地停止解释为远程取消。SQLite 事务不能与文件系统形成全局原子快照。

首次提交引用的任务修订已被新修订取代时返回 `STALE_TASK_REVISION`；适用的业务确认已失效或仍待澄清时返回 `BUSINESS_CLARIFICATION_REQUIRED`。这些结果不将历史审核或冻结数据改写为新版本，也不证明人工来源已经验证。

**T027-A 离线子范围**：本地 `submit_offline` 复用 v2 快照及冻结字节，将资格消费、Attempt 和提交意图写入同一个 SQLite 事务；重复操作只读取已有状态，冲突拒绝。默认业务确认、Host 授权验证器及离线传输均不提供通过路径，测试仅在进程内替换私有函数；它不是 MCP 提交工具或真实发送器。未解决的结构冲突和多包装版本阻断执行。提交意图不证明远端接收，中断或超时保留不确定状态，不自动重提。本地事务不保证远端恰好一次。真实授权交接、提交前最终复核及发送／恢复仍属于后续工作。

**用途**：提交一次已获适用授权的绘图操作；`stage: form|mock` 区分形态组合及包装 Mock 组合。Server 不提供 `build_prompt`、不调用独立 LLM；Host Agent 根据运营需求和反馈构造实际绘图提示词。准备与绘图不同，绘图具有收费及文件副作用。

**输入**：`task_id`、`revision`、`input_digest`、`stage`、已准备的 `prompt_revision`、`prompt_digest`、`execution_digest` 及适用的已确认形态版本/摘要。Server 读取已持久化的实际提示词和冻结图片字节，复核任务、修订、提示词、内容摘要、模型、端点、分组、输出和操作范围，核对适用 Host 授权及本地资格；使用与快照一致的冻结字节提交，不得静默修改提示词、替换图片或扩大范围。关键内容变化使旧确认失效；Host 可验证性仍待逐一实测。

**授权**：每次可能收费的真实外部请求之前，均须取得并核验对应本次请求的独立明确授权，包括适用的生成、重试、模型切换、查询及下载；收费属性不明时不得推定免费。范围授权可描述整体执行和费用风险上限，但不能代替逐次请求许可，也不得将上一次请求许可复用于另一次。Server 须核对当前快照、请求身份、授权来源与有效性，未能落实实际授权核对时停止请求。普通工具调用、模型文本、`approved=true` 或 API Key 不是证据。unknown 无法查询后的新尝试仍须风险告知及独立风险授权，新的请求许可不能绕过 unknown 安全规则。当前真实 Host 来源、逐次重试和下载授权交接尚未验证，生产默认拒绝；既有隔离 Scope 测试不证明真实收费授权。

**输入与审核**：形态阶段仅发送 1–6 张形态参考图，不含设计图或旧候选；Mock 阶段仅发送已确认形态组合原图及 1–2 张设计图，不含原始形态图。每阶段一次正常绘图输出一张六视图组合图；人工审核形态后才能生成 Mock，人工审核 Mock，可明确请求修订并保留历史版本。Host 交接能力与防伪均须实测。

**输出和恢复**：返回 `task_id`、`prompt_revision`、`prompt_digest`、操作/attempt、阶段、状态及可得上游 ID；本地操作标识和摘要约束并发重复提交。每模型/端点最多 3 次，当前 Sunburst 和 Flare 同一接口最多合计 6 次，仅安全且授权覆盖时执行；普通等待 5 秒，429 依有效 Retry-After，缺失则停止；429、5xx 或超时本身不证明远端未执行。结果不明先查原 ID，不可查则保持 unknown，不自动重提或切换。禁止 SDK 隐式重试。

## get_product_image_task

**用途**：只读查询指定 `task_id` 及可选 `attempt_id`，默认列出该任务的当前尝试及可追溯历史；可按已获得的上游 ID 进行有界只读状态查询，禁止通过查询隐式触发收费重提。**副作用**：可更新本地记录以反映有据可查的上游状态；不生成图片。

**输出**：分别报告形态组合与包装 Mock 组合的阶段、版本、attempt、产物和人工审核状态，并返回 `task_id`、`revision`、`previous_attempt_id?`、本地/上游/交付三个独立状态、unknown 风险、可恢复动作、时间及可得绘图 cost；cost 单位为 ฿、缺失为 unknown，用户提供的 1 ฿ = ¥1.35 仅为参考值。仅在文件可读、摘要与任务和版本归属核验通过时返回产物引用；上游成功不等于交付成功，未人工审核不得标记批准。保留历史版本；查询不触发重新生成。

Team Mode 下，已交付且当前文件核验通过的产物在 `file.path` 返回本地路径；缺失、损坏或身份未核验时不返回路径。公开工具包括 `prepare_product_image`、`submit_product_image`、`get_product_image_task` 和 `get_product_image_file`；诊断探针只用于隔离测试。

`get_product_image_task` 对当前可核验的已交付产物同时返回 MCP `ImageContent`，预览长边不超过 1024 像素；结构化任务数据和原始文件路径保留，图片 Base64 不放入文本 JSON。单产物查询发现文件损坏或缺失时返回工具错误；任务列表继续报告异常状态。预览只来自数据库中已登记且摘要重新核验的 Artifact，不能以客户端路径指定读取对象。

工具还返回已核验原图的本地 Markdown 图片引用，供支持的 Host 在回复正文中使用，同时保留原文件路径。是否渲染取决于实际 Host 界面。

`get_product_image_file` 以 Task、Attempt、Stage、Revision 和 Artifact 身份读取已交付且重新核验的原图，将原图作为 MCP ImageContent 返回；不接受客户端提供文件路径、不访问供应商。Host 能否把图片保存到其工作区及呈现文件由 Host 决定。

2026-11-12 在 Claude Desktop 4.23118.1.0 实测：Claude 保存了真实 Form 原始 PNG，保存文件 SHA-256 与 Artifact 登记摘要一致，并在对话中提供文件卡片及侧边图片查看器；该结果不是正文内嵌图片。既有 ImageContent 和本地路径继续可用。

已明确记录的 Team 负责人概念原型审核，允许用于内部 Mock；背面、侧面和拉链的实物准确性仍未验证。Team 来源为运营声明，不是密码学身份或真人在 Host 中确认的证明；Strict Mode 原有审核来源策略不变。

**已实现的单产物子范围**：传入 `task_id`、`stage`、`revision`、`attempt_id` 和 `artifact_id`，返回记录的上游及交付状态、当前文件校验、产物审核及来源信息。当前文件经受控根目录、资源、格式及摘要校验，且历史状态为上游成功和已交付时，`artifact_reference` 为同次校验字节编码的 data URI；否则为 null。`mime.detected` 是当前检测值，`mime.historical` 为 unknown。审核来源仍为 unverified。

**T042 本地只读子范围**：仅传 `task_id` 或附带 `attempt_id`，可读取当前修订、历史阶段、候选和尝试，并分别报告本地发送标记、持久化远程状态、观察和来源核验结论、产物当前完整性与审核、生成费用及查询费用。费用仅为按币种已知小计，完整性默认 unverified；历史时间缺失为 unknown。受控时间证据和可信终态均成立时才报告耗时，生产时间来源验证器默认拒绝。查询不访问供应商，不授予执行资格；数据库读取使用同一 SQLite 只读事务，文件与数据库之间不构成原子快照。真实供应商、Host 和完整 T042 验收仍未通过。

## 状态与错误

返回本地任务状态、上游尝试状态和本地交付状态三个独立字段，定义见 [数据模型](../data-model.md) 与 [架构审查决策](architecture-review.md)。上游成功而下载/保存失败时分别报告；`unknown` 包括可能仍运行及重复费用/产物风险，不标记失败或取消。该自定义业务任务接口不声明实现 MCP Tasks Extension。

错误语义：无效参数、禁止访问、缺失权限、已声明限制下文件超限和确认缺失为可纠正工具执行错误，按 SDK 返回 `isError: true`；协议无效请求由协议层处理。持久化失败或授权验证失败 fail-closed。发生未知状态时输出结构化 unknown 和风险；是否采用 `isError` 及 schema 兼容由锁定 SDK 协议检查确认，不能把未知当作业务成功。详细错误脱敏，stdio stdout 仅协议，stderr 不含秘密。

## 当前阻断与兼容范围

三 Host 替身测试的版本、允许/拦截方式及可见元数据见 [Host 许可测试记录](host-permission-probe-2026-11-02.md)。测试未验证 Server 可独立核对身份、任务范围或费用授权；DSH 默认调用未出现人工审批，测试专用 guard 不代表默认行为。用户取消的仅是未证实凭证时禁止收费的测试门禁，业务授权核对仍是 FR-012 要求；具体核对手段和各 Host 人工交互仍需设计验证。默认模型、端点和分组已由用户明确，但任务中的模型选择、逐组合图片限制和 Host 兼容仍需确认。以上接口是评审草案，不得宣称实现或直接启动收费调用。

### 输入修订的来源边界（隔离实现）

已有任务的资料变化应按任务及当前修订绑定来源、原有和目标资料的顺序与内容；关联记录的来源声明、普通字段或标识不能单独证明人工决定。准备过程中对已实现的修订记录执行范围、期限和来源复核，提交时复核关联记录；当前默认来源验证不接受真实来源。MCP 工具尚未完成可信 Host 的修订记录交接，不能将隔离测试通过视为生产可用。

`prepare_product_image` 可引用既有 `revision_decision_id`；该标识仅用于查找范围绑定记录，不能作为可信确认。生产默认验证器仍拒绝尚未证实的来源，记录签发与 Host 交接未完成。

Team Mode 可由本地团队操作员记录明确的输入变更准备决定（`team-local-input-change` / `team-explicit-preparation`）；现有任务、原修订、输入摘要、目标素材和有效期绑定检查仍适用。该记录是本地操作声明，不是 Host 真人签名，也不单独开启真实生成；Strict Mode 保持默认拒绝。

2026-11-13 起 Team Mode 为默认；进程环境显式设置 `TEAM_MODE=false` 选择 Strict Mode。现有部署如依赖默认 Strict，应在升级前显式配置。真实生成、远程查询和下载的独立开关仍默认关闭；模式选择不会自动发送网络请求。

### 不确定性预览的离线追溯

无收费提交可在适用业务决定和独立收费授权替身均通过时记录预览依据，提交结果及现有产物查询分别返回关联决定、假设、未验证结构和当前决定状态。历史无依据返回 unknown；撤销后保留当时依据。此能力不证明 Host 已验证、收费授权已取得或已完成 T042 的任务汇总。

## 2026-11-12 Team MVP 模式（已批准，未启用）

负责人提出内部 Team MVP：管理员配置凭据，工具调用代表一次业务操作，不依赖独立签发服务，不自动重试收费请求；Strict Authorization Mode 的独立可信授权机制延期。普通 MCP 调用可能由自动放行的 Agent 发起，不能证明自然人确认。宪法 4.0.0 将 Team Mode 设为默认，真实生成开关默认关闭。Team Form 与 Mock 的 MCP 提交已接入既有 SQLite Attempt、发送边界和单次 HTTPS 传输；真实 Form 已交付，Mock 已获网关接受，其完成状态尚待查询。

### Team 原任务查询与交付（离线替身）

Team Get 默认只读取本地数据；调用方须显式提供 `refresh_remote=true`，且处于 Team Mode、管理员开启 `ENABLE_REAL_GENERATION`、`ENABLE_TEAM_QUERY` 并将 `TEAM_GATEWAY_URL` 设置为实际固定网关 Edits 地址，才会尝试受控远程刷新。下载还须开启 `ENABLE_TEAM_DOWNLOAD` 并通过 `TEAM_DOWNLOAD_HOSTS` 配置精确域名白名单。Team 查询核验原 Attempt 和上游 ID，下载复用 T049 和 T048；已登记 Artifact 不再下载。下载及本地保存失败不重新生成，Mock 仍要求有效 Form 审核。

**Team Mode 摘要政策（负责人批准）**：受控网关响应及原 Attempt／上游 Task ID 绑定可作为来源证据；网关未提供独立预期摘要时，允许将下载后计算的 SHA-256 仅作为本地文件完整性记录，明确标注供应商独立摘要未提供。Strict Mode 仍要求独立预期摘要。TLS、DNS、图片校验、资源预算和无覆盖发布要求不变。本政策不代表生产下载已接通或真实供应商已验证。
